🔎 이미지 분석
메타데이터가 없는 이미지를 분석해 이미지 생성용 영어 프롬프트 1개를 추정합니다. API 키는 Ultra Random Prompt v7과 같은 localStorage 키 이름을 공유합니다.
이 기능은 이미지 분석 전용입니다. 원본 메타데이터 파서에는 영향을 주지 않으며, 분석 결과는 이 창 안에서만 확인·복사합니다. 닫기는 보존, 초기화는 삭제입니다.
Ollama 모델 선택
Ollama 이미지 분석은 비전(Vision) 지원 모델에서만 정상적으로 동작합니다.
일반 텍스트 모델은 이미지를 분석할 수 없으며, Vision 후보로 인식되지 않는 모델은 분석 실행 전에 차단됩니다.
웹 배포(HTTPS) 페이지에서는 브라우저의 localhost/CORS/Local Network Access 정책 때문에 연결이 차단될 수 있습니다. 가장 안정적인 방식은 이 HTML을 다운로드해 로컬에서 열고 사용하는 것입니다.
한국어 지시어도 입력할 수 있지만, 최종 분석 결과는 이미지 생성용 영어 프롬프트로 고정됩니다.
Ollama 선택 시 연결 상태를 확인합니다.
Ollama 앱 실행 후 목록 새로고침을 누르세요.
분석 지시어 선택
커스텀 분석 지시어는 한글로 적어도 내부적으로 해석되어 영문 프롬프트에 반영됩니다. 명시 요청이 없는 한 인물·의상·배경·조명·구도 등 이미지 고유의 모습은 최대한 유지합니다.
